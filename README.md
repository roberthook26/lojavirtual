# NorteByte

Site responsivo de serviços e produtos para computadores e notebooks, com agendamento pelo WhatsApp.

## Executar

Abra `index.html` em um navegador. O projeto é estático, sem dependências ou etapa de build.

## Agendamento

O formulário prepara uma mensagem com nome, cidade, serviço e detalhes do equipamento e abre o WhatsApp no número `+55 48 99840-9515`. Cada produto também tem um atalho para consultar preço, disponibilidade e compatibilidade.

## Publicar no GitHub Pages

Nas configurações do repositório, acesse **Pages**, escolha **Deploy from a branch**, selecione a branch `main` e a pasta `/ (root)`, então salve. O site ficará disponível em `https://roberthook26.github.io/lojavirtual/` após a publicação.

## Conteúdo e arquivos

- Serviços de formatação, upgrade, limpeza e reparo de computadores e notebooks.
- A vitrine apresenta componentes e acessórios; as imagens ficam na pasta `imag/`.
- A imagem principal é local. A imagem da seção de assistência e as fontes tipográficas são carregadas de serviços externos.
